# 브랜드 원본

여기 있는 파일은 **서빙되지 않는다.** `public/`에 두면 누구나 내려받을 수 있고,
그러면 잘못된 태극 순서가 담긴 `-original` 판까지 공개된다.

| 파일 | 무엇 |
| --- | --- |
| `jamtong-app-icon.png` | 앱 아이콘 원본 (1254×1254). 모든 아이콘이 여기서 나온다 |
| `jamtong-korean-wordmark.png` | 워드마크 원본 (2172×724). 로고가 여기서 나온다 |
| `*-original.png` | 태극 순서를 고치기 전 판. 되돌릴 일이 있을 때를 위해 남긴다 |

## 태극 순서

처음 받은 두 장은 **파랑이 위, 빨강이 아래**였다. 국기와 반대다.
두 호의 색을 맞바꿔 고쳤고, 그 판이 지금의 원본이다.

색을 통째로 치환하면 안티에일리어싱과 그라데이션이 깨진다. 픽셀마다 배경 대비
덮인 정도를 구한 뒤 반대쪽 원색으로 다시 합성했다. 앱 아이콘에는 한반도
워터마크(`#e4ebf5`)가 옅은 파랑이라 '푸른 픽셀'만으로는 호를 가려낼 수 없어서,
덮인 정도 0.18 이상인 몸통을 먼저 잡고 그 마스크를 2px 부풀려 가장자리까지
포함했다. 워터마크는 0.08 수준이라 걸러진다.

**원본을 새로 그려 넣을 때는 태극 순서를 먼저 확인할 것.**

## 다시 뽑기

```
pnpm brand
```

원본의 그림 위치가 바뀌면 `scripts/build-brand.ts`의 `ICON_ART`·`WORD_ART`
자르기 좌표를 다시 재야 한다.
