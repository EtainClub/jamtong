# 잼공 R2 「가리기」 문항 점검 (2026-11-28)

> `docs/jamgong-roadmap.md` R2. 문항은 `src/content/study/sort.ts`(사실·주장 가리기)와 `src/content/study/numbers.ts`(숫자 읽기).
> 초안은 Codex(GPT)가 claim만 보고 썼다. 에이전트가 문항마다 원본 claim과 나란히 놓고 읽어 고쳤다.

## 만든 방법

1. 후보를 뽑았다. 확인된(verified) claim 730개(업적 전부 + 정책의 주장·해석·의견 전부 + 정책 사실 140개)와 업적 핵심 숫자 95개다.
2. Codex에게 사실·주장 가리기 70개와 숫자 읽기 30개를 맡겼다. 규칙은 "정답은 원본 claim의 층", "누가 말했는지를 빼도 층이 같아야 한다", "출처 설명에 답을 적지 않는다"였다.
3. `pnpm validate` 검사를 먼저 돌렸다(`src/content/study/validate.ts`).
4. 문항마다 원본과 대조해 읽었다. 아래가 그 결과다.

## 사실·주장 가리기 — 70개 → 63개

| 판단 | 수 | 문항(초안 번호) |
|---|---|---|
| 그대로 | 50 | |
| **뺌 — 정답이 둘로 읽힌다** | 7 | |
| ㄴ 산수로 낸 값을 "해석"으로 물음 | 4 | 계란 단가 반올림, 1인당 국가채무, 출산·육아 지원 합산, 조사 시간 합계 |
| ㄴ 분석을 "주장"으로 물음 | 1 | 한국금융연구원 환율 분석(원본 층은 CLAIM이지만 문장은 분석이다) |
| ㄴ 요청·지시를 다른 말로 바꿈 | 2 | 대통령의 방산 협력 "요청"을 "필요하다"로, 가짜뉴스 엄정 처리 "지시"(의견으로 읽힌다) |
| **고침 — 출처를 잘못 붙였다** | 7 | 이 위키가 쓴 해석(assertedBy 없음)인데 출처를 기사·법 조문·통계처럼 적었다 → "잼통 위키의 정리 글"로. 법 조문이라고 적으면 사실로 읽힌다 |
| **고침 — 주장한 사람을 잘못 붙였다** | 2 | 인구정책 비판(다른 비판자의 말에 조영태 교수 이름), 건강검진비 과세(조세 전문가의 말에 박수영 의원 이름) |
| **고침 — 더 좋은 문장으로** | 1 | 운임 차액 지원: "재시행한다"(사실로 읽힘) → "지원으로 도입이 늘었다"(증가 원인은 정부 판단) |
| 문법 | 전부 | "~다라는 분석" → "~다는 분석", "~이다라는" → "~이라는" |

- 이 위키가 쓴 해석에 "잼통 위키의 정리 글"이라고 붙인 것은 일부러 한 일이다. **이 위키의 풀이도 해석이다**는 것을 같이 배우게 한다.
  처음에 "사실 확인 정리"라고 적었더니, 검사가 "출처에 답(사실)이 샌다"로 잡아 고쳤다.
- 최종 63개: 사실 22 · 주장 23 · 해석 10 · 의견 8. 정책 단원 30곳과 업적 단원에 걸쳐 있다.

## 숫자 읽기 — 30개 → 25개

| 판단 | 수 | 문항 |
|---|---|---|
| 그대로 | 25 | 실적 11 · 잠정·누적 6 · 전망·추정 2 · 목표·계획 6 |
| **뺌 — 갈래에 맞지 않는다** | 2 | 북극항로 거리 36% 단축, 7,400km 단축. 두 항로를 비교한 값이라 실적·잠정·전망·목표 어디에도 맞지 않는다 |
| **뺌 — 틀리게 가르칠 수 있다** | 3 | 8월 출생아 수, 8월 합계출산율, 26개월 연속 증가. 월간 인구동향은 통계청이 잠정치로 낸다. 근거 문장에 "잠정"이 없다고 "확정된 실적"으로 가르치면 틀린다 |

- 검사가 "단서 낱말이 없다"고 잡은 3건은 판단이 맞았다(분석 결과로 낸 추정, 성남시의 계산, "지원하기로 했다"는 계획).
  그래서 단서 목록에 "분석한 결과", "~의 계산", "하기로 했"을 더했다.
- 전망·추정이 2개뿐이다. 업적 핵심 숫자에는 전망이 드물다. R4에서 정책 claim의 전망 숫자(잠재성장률 등)로 채운다.

## 기계 검사 (`pnpm validate`)

- **가리기**
  - 정답 = 원본 층
  - 주장이면 주장한 쪽 = 원본 assertedBy
  - 확인된 claim만
  - core에 "밝혔다·에 따르면" 같은 귀속이 남지 않음
  - 출처 설명에 사실·주장·해석·의견이 나오지 않음
  - core는 "다."로 끝나는 한 문장
- **숫자**
  - 핵심 숫자와 근거 claim이 이어져 있음
  - 고른 갈래의 단서 낱말이 근거에 있음
  - "실적"이라면서 근거가 전망·목표·잠정을 말하지 않음

## 남은 것

- 해석과 주장의 경계는 원본 claim의 층에 기댄다. 원본 층이 애매하면 문항도 애매해진다. 그런 문항은 빼는 쪽으로 했다(위 7개).
- 실제 사용자의 정답률이 유난히 낮은 문항은 문장이 모호하다는 신호다. 지표를 보고 다시 고친다.
