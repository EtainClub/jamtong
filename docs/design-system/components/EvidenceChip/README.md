# EvidenceChip

수치나 단정 옆에서 근거가 몇 건인지 알리고, 누르면 근거를 펴는 칩.

이 제품의 약속이 "모든 중요한 표현 뒤에 근거가 있다"이므로, 이 칩이 붙지 않은
수치는 화면에 나가서는 안 됩니다. 가장 많이 쓰이고 가장 중요한 컴포넌트입니다.

## 소비자가 넘기는 것

- `claimId` — 펼 주장의 id
- `count` — 그 주장이 기댄 자료 수
- `label`(선택) — 한 줄에 칩이 여럿일 때 무엇의 근거인지 구분하는 말

## 규칙

- **알약 모양**(`radius-pill`)입니다. 누를 수 있는 것이기 때문입니다.
- **무채색입니다.** `stone` 테두리에 `graphite` 글자. 색을 쓰지 않는 이유는
  이 시스템에서 색이 자료를 뜻하기 때문입니다 — 칩은 자료로 가는 문이지
  자료가 아닙니다.
- 근거가 0건이면 칩을 그리지 않습니다. 대신 그 수치 자체를 렌더링하지 않습니다.
  빈 칩은 "근거가 없다"를 "근거를 못 찾았다"처럼 보이게 합니다.
- 값 **아래**에 옵니다. 옆에 두면 값의 일부처럼 읽힙니다.
- 검증 전 주장에는 `StatusBadge`를 칩 옆에 함께 둡니다. 칩의 색을 바꾸지
  않습니다 — 근거의 개수와 검증 여부는 다른 정보입니다.
