# EvidenceChip

수치나 단정 옆에 붙어 그 근거가 몇 건인지 알리고, 누르면 근거 패널을 여는 칩.

이 시스템에서 가장 많이 쓰이고, 가장 중요한 컴포넌트입니다. 제품의 약속이
"모든 중요한 표현 뒤에 근거가 있다"이므로, 이 칩이 붙지 않은 수치는 화면에
나가서는 안 됩니다.

## 언제 쓰는가

- 핵심 수치 카드 아래
- 연표 항목, 관계도의 선 설명, 쉬운 설명의 각 장면
- 도입부 요약문 아래 — 가장 많이 읽히는 주장이므로 여기에도 붙입니다

## 소비자가 넘기는 것

- `claimId` — 열 주장의 id
- `count` — 그 주장이 기댄 자료 수
- `label`(선택) — 한 줄에 칩이 여럿일 때 무엇의 근거인지 구분하는 말

## 규칙

- **근거가 0건이면 칩을 그리지 않습니다.** 대신 그 수치 자체를 렌더링하지
  않습니다. 빈 칩은 "근거가 없다"를 "근거를 못 찾았다"처럼 보이게 합니다.
- 칩은 언제나 값 **아래**에 옵니다. 값 옆에 두면 값의 일부처럼 읽힙니다.
- 검증 전 주장에는 `StatusBadge`의 검증 전 배지를 칩 **옆에** 함께 둡니다.
  칩의 색을 바꾸지 않습니다 — 근거의 개수와 검증 여부는 다른 정보입니다.
