# SectionHead

씬의 머리. 구분선, 제목, 리드 한 문단으로 "여기서 새 장면이 시작된다"를 알립니다.

레이아웃 셋에서 13번 반복되던 마크업을 하나로 모은 것입니다. 같은 것을 열세 번
적어 두면 여백 하나 고칠 때 열세 곳을 고치게 됩니다.

## 소비자가 넘기는 것

- `scene`(선택) — `data-scene` 앵커. 씬 내비게이션과 AI 안내가 이 값으로 화면을 찾습니다
- `heading`, `lede`(선택)
- `first` — 첫 씬은 위 여백을 두지 않습니다

## 규칙

- 씬과 씬 사이는 `space-20`(80px). 이 간격 하나가 장면의 끝을 알립니다.
  좁히면 스크롤이 이어지는 한 편의 글처럼 읽힙니다.
- 리드는 34em을 넘기지 않습니다. 길어지면 읽는 화면이 됩니다.
- 제목은 명령이 아니라 **질문이나 관찰**로 씁니다 — "지수는 오르고, 또 내렸습니다",
  "누가 무엇을 하고 있나". 화면을 보게 만드는 말이어야 합니다.
- 앵커를 붙인 씬은 `scroll-margin-top`으로 고정 헤더 높이만큼 비웁니다.
