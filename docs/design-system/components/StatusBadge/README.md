# StatusBadge

진행 상태와 검증 상태를 알리는 배지. 두 축이 서로 다른 정보이므로 색도 다르게 씁니다.

## 두 축

**진행 상태** — 완료 / 추진 중 / 계획.
계획을 성과처럼 보이게 하면 콘텐츠 전체가 신뢰를 잃습니다. "계획"에도 또렷한
배지를 주고 숨기지 않습니다.

**검증 상태** — 검증 전.
출처가 확정되지 않은 주장에 붙습니다. `warm-400`을 쓰는 이유는 이것이 오류가
아니라 "아직 모른다"이기 때문입니다.

## 소비자가 넘기는 것

- `status` — `done` | `ongoing` | `planned`
- `verified` — 거짓이면 검증 전 배지를 함께 그립니다

## 규칙

- 진행 상태 배지는 카드의 **첫 줄**에, 분류 태그보다 앞에 둡니다.
- 검증 전 배지는 근거 칩 **옆**에 둡니다. 근거를 확인하려는 순간에 함께 보여야
  합니다.
- 미검증 항목은 카드 테두리도 `warm-400`의 옅은 쪽으로 바꿉니다. 배지를 놓친
  사람도 카드 단위로 알아볼 수 있어야 합니다.
- 완료가 아닌 것을 완료로 보이게 하는 어떤 축약도 하지 않습니다.
