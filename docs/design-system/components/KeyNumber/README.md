# KeyNumber

핵심 수치 하나를 카드로 보여줍니다. 스크롤을 멈추게 하는 것은 문장이 아니라 숫자입니다.

## 소비자가 넘기는 것

- `label` — 무엇의 수치인지
- `prefix`(선택) — "약", "최대" 같은 한정어. **숫자와 분리해서 넘깁니다**
- `value`, `unit`
- `caption`(선택) — 측정 조건
- `claimId` — 근거. 없으면 카드를 그리지 않습니다

## 규칙

- **한정어를 값에 섞지 않습니다.** `"약 32"`처럼 한 문자열로 넘기면 좁은 화면에서
  "약"과 "32" 사이가 줄바꿈되어 숫자가 깨집니다. `prefix`로 분리하고 값 전체에
  `white-space: nowrap`을 겁니다.
- 숫자는 `heading-sm`(32px/300) 크기에 고정폭 자릿수. 굵게 키우지 않습니다 —
  크기로 충분합니다.
- **숫자는 `ink`입니다.** `navy`는 그 수치가 차트나 지도에서 주인공일 때만 씁니다.
  카드마다 색을 칠하면 색이 뜻을 잃습니다.
- 조건이 있는 수치는 `caption`을 비우지 않습니다. "7~10월 기준" 같은 전제를
  숨기면 수치가 오도합니다.
- 미검증 주장을 가리키면 테두리를 `pending`으로 바꾸고 검증 전 배지를 답니다.
