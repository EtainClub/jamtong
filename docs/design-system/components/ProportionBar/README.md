# ProportionBar

두 개 이상의 값을 길이로 비교하는 막대. 프레이밍은 비교군이 없을 때만 작동하므로,
이 시스템에서 비교는 장식이 아니라 논지입니다.

## 소비자가 넘기는 것

- 항목마다 `name`, `value`, 표시 문자열
- `highlight` — 주인공 항목. 강조색을 받습니다
- `note` — 비교의 전제 조건

## 규칙

- **길이는 값에 정비례합니다.** 시각적 과장을 넣지 않습니다. 차이가 작으면
  작게 보이는 것이 맞습니다.
- 축은 0에서 시작합니다. 밑동을 자르면 변화가 실제보다 크게 보입니다.
- 주인공은 `ice-400`, 비교군은 `ink-500`. 비교군이 주의를 끌 대상이면
  `warm-500`을 씁니다(대조 항로처럼).
- **`note`를 비우지 않습니다.** "78,000톤 선박, 7~10월 기준" 같은 조건을 숨기고
  수치만 보여주면 오도가 됩니다.
- 누적 막대(100%)와 비교 막대(개별 값)는 다른 것입니다. 누적은 한 전체의 구성을,
  비교는 서로 다른 대상의 크기를 말합니다. 섞지 마세요.
