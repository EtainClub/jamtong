# Caveat

아직 확정되지 않은 것, 전제 조건, 한계를 밝히는 블록.

쉽게 설명할수록 한 문장이 감당하는 주장이 커집니다. 확정되지 않은 것을 확정된
것처럼 전하지 않기 위해 이 블록이 필요합니다.

## 두 형태

**단서(caveat)** — `warm-400` 왼쪽 선 + 옅은 바탕.
"러시아 제재에 따라 이 길을 쓸 수 있을지가 달라집니다"처럼 결론을 흔드는 조건.

**주석(note)** — `line-strong` 왼쪽 선, 바탕 없음.
"일별 종가 전체가 아닙니다"처럼 읽는 법을 알려주는 조건.

## 규칙

- 단서에는 근거 칩을 붙입니다. 단서도 주장이고, 주장에는 근거가 필요합니다.
- 본문 **아래**에 둡니다. 위에 두면 본문을 읽기 전에 방어부터 하게 됩니다.
- 접거나 숨기지 않습니다. 펼쳐야 보이는 단서는 없는 것과 같습니다.
- 문장을 완곡하게 다듬지 않습니다. 조건을 흐리면 밝히는 의미가 사라집니다.
