# 잼통

읽는 위키가 아니라 이해하는 위키.

업적·사건·맥락·근거를 텍스트 더미가 아니라 시각적 경험으로 전하는 참여형 위키의
디자인 시스템입니다. 스토리 셋(북극항로·성남 판교대장·주식시장 개선)을 만들면서
내린 결정을 사후에 정리한 것이지, 먼저 그려 놓고 따라간 규칙이 아닙니다.

## 이 시스템이 지키는 것

**근거가 없으면 그리지 않는다.** 이 제품의 모든 화면 규칙은 여기서 나옵니다.
수치 옆에는 근거 칩이 붙고, 관계선에는 의미와 출처가 붙고, 검증되지 않은 것은
검증되지 않았다고 표시됩니다. 스키마가 이를 강제하므로, 디자인도 그 상태를
드러낼 자리를 항상 비워 둬야 합니다.

**설명은 짧게, 화면은 움직이게.** 긴 글을 읽혀야 이해되는 화면은 실패한 화면입니다.
문장을 늘리는 대신 지도를 끌게 하고, 시점을 옮기게 하고, 관계를 눌러 보게 합니다.

**의미 없는 움직임은 만들지 않는다.** 모션은 시간·거리·변화·관계·흐름 중
하나를 설명할 때만 씁니다. 장식으로 움직이는 것은 없습니다.

## 톤

Editorial · Documentary · Data Journalism.
어두운 바탕에 얼음빛 강조 하나. 카드 수십 개를 늘어놓지 않고, 과한 그라디언트와
발광을 쓰지 않고, 모든 것을 둥근 상자에 담지 않습니다.

기준이 되는 질문은 "예쁜가"가 아니라 **"이 화면을 보고 나서 전보다 더 정확히
아는가"** 입니다.

## 색

단일 테마입니다. 어두운 바탕이 이 제품의 기본값이고, 밝은 테마는 없습니다.
자료를 들여다보는 화면이라 주변 빛을 줄이는 쪽이 맞다고 판단했습니다.

- `ink-800`이 페이지 바탕, `ink-700`이 그 위에 떠오른 모든 면입니다.
  `body`에는 반드시 `background`(=`ink-800`)를 칠합니다.
- 강조는 **`ice-400` 하나**입니다. 주항로, 활성 상태, 링크, 확인된 사실이 전부
  이 색입니다. 강조가 둘이 되면 어느 쪽을 봐야 할지 알 수 없어집니다.
- **`warm-400`은 오류가 아니라 '아직 확정되지 않음'입니다.** 검증 전 표식,
  주장·해석, 하락 구간, 대조 항로에 씁니다. 빨강을 쓰지 않는 이유는, 이 제품에서
  경고해야 할 것이 대부분 '틀렸다'가 아니라 '아직 모른다'이기 때문입니다.
- 면을 나눌 때는 그림자가 아니라 `line`을 씁니다.

## 글자

한 가족(`sans`)만 씁니다. 대신 굵기와 크기의 차이를 크게 벌립니다 —
`story-title` 700과 `body` 400 사이가 이 시스템의 전체 대비입니다.

**숫자는 언제나 `tabular-nums`입니다.** 지도를 끌거나 차트를 훑는 동안 자릿수가
흔들리면 읽을 수 없습니다. `number-lg`, `number-md`를 쓰는 곳에는 예외 없이
`font-variant-numeric: tabular-nums`를 함께 겁니다.

`label` 스타일은 대문자 자간과 `text-muted`를 함께 씁니다. 11px 아래로는
`text-muted`를 쓰지 않습니다 — 읽히지 않습니다.

## 여백

`space-20`(80px)이 씬과 씬 사이입니다. 이 간격 하나가 "여기서 한 장면이 끝났다"를
알립니다. 그보다 좁으면 스크롤이 이어지는 하나의 글처럼 읽힙니다.

화면 좌우 여백은 어느 폭에서나 최소 `space-5`(20px)를 지킵니다.

## 반경

`radius-xl`(12px)이 카드의 기본값이고, `radius-full`은 **데이터를 나타내는
것**에 씁니다 — 칩, 배지, 막대, 점. 둥근 정도가 "이건 값이다"를 말합니다.

## 모션

토큰으로 두지 않고 규칙으로 둡니다. 값은 `--ease-out-expo`
(`cubic-bezier(0.16, 1, 0.3, 1)`) 하나를 공유합니다.

| 무엇 | 시간 |
| --- | --- |
| 마이크로 인터랙션 (호버, 포커스) | 150–250ms |
| 패널·드로어 전환 | 250–400ms |
| 씬 전환, 관계 나타나기 | 320–420ms |
| 스토리 애니메이션 (배, 시점) | 사용자 제어 |

**끌고 있는 동안에는 전환을 끕니다.** 스크럽 중에 보간이 걸리면 손과 화면이
어긋납니다.

`prefers-reduced-motion: reduce`에서는 자동 넘김과 카운트업을 끄고 최종 상태만
보여줍니다. 멈출 수 없는 자동 재생은 접근성 실패입니다.

## 접근성

- 드래그로만 되는 조작은 만들지 않습니다. 지도의 배는 `role="slider"`이고
  화살표·Home·End로 똑같이 움직입니다.
- 모든 씬에 스크린리더용 서술을 둡니다. 그 서술이 "Card First, **Text Later**"의
  Text입니다.
- 포커스 링은 `ice-400` 2px, offset 3px. 키보드 사용자에게만 보입니다.
- 본문 대비는 모든 조합에서 4.5:1 이상을 지킵니다. `text-muted`(#6f819b)는
  `ink-800` 위에서 약 5.4:1로, 11px 이상에서만 씁니다.

## 이 시스템을 쓸 때

컴포넌트 문서는 소비자가 **무엇을 넘겨야 하는지**를 먼저 말합니다.
특히 근거를 다루는 컴포넌트는 근거가 비었을 때 렌더링하지 않는 것이 기본 동작입니다 —
빈 상태를 그리지 말고, 아예 그리지 마세요.
