# 잼통

읽는 위키가 아니라 이해하는 위키.

## 이 시스템이 어디서 왔는가

**형태는 ElevenLabs에서, 색은 사진 한 장에서 왔습니다.**

표면·타이포·간격·반경·그림자 규칙은 ElevenLabs 디자인 시스템의 값을 그대로
받았습니다. 따뜻한 흰 바탕, 순수 검정 잉크, 헤어라인 테두리, 알약 버튼,
가벼운 디스플레이 서체.

색은 이재명 대통령 취임 선서 사진에서 뽑았습니다 — **남색 정장과 버건디 넥타이**.
밝은 빨강을 쓰지 않은 이유가 있습니다. 어두운 붉은색은 경보로 읽히고, 사진의
넥타이는 경보가 아니라 절제입니다.

### 무엇을 바꿨는지

| | ElevenLabs | 잼통 |
| --- | --- | --- |
| 악센트 | Violet #0447ff · Ember #ff4704 | Navy #16366b · Burgundy #8a2233 |
| 디스플레이 서체 | Waldenburg (비공개 서체) | Pretendard 300 — 한글 지원이 필요해 대체했습니다 |
| UI 서체 | Inter | Pretendard — Inter와 자폭이 맞고 한글을 덮습니다 |
| 고정폭 | Geist Mono | IBM Plex Mono |
| 의미색 | 없음 | `pending` 하나 추가 |

서체 셋 다 원본이 아닙니다. Waldenburg는 비공개 서체이고, 이 제품은 한국어가
본문이라 한글을 덮는 서체가 필요했습니다. 대체했다는 사실을 숨기지 않습니다.

## 가장 중요한 규칙

ElevenLabs의 핵심 규칙은 **"악센트색은 제품 시각물에만, UI 요소에는 금지"**입니다.
이 규칙을 그대로 가져왔고, 이 제품에서는 특별히 잘 맞습니다.

> **UI는 무채색, 색은 데이터에만.**

버튼·카드·테두리·탭은 잉크와 회색으로만 만듭니다. 남색과 버건디는 **지도의 항로,
차트의 선, 관계도의 간선, 비교 막대** — 자료를 나타내는 것에만 씁니다.

그래서 화면에 색이 보이면 그건 언제나 자료입니다. 장식으로 칠한 색이 없으므로,
색이 있는 곳을 보면 됩니다.

## 색이 맡은 일

각 색에 일이 하나씩입니다. 하나가 여러 일을 하면 화면마다 뜻이 달라집니다.

| 색 | 뜻 |
| --- | --- |
| `navy` | 주인공. 주항로, 확인된 사실, 지금 보고 있는 것 |
| `burgundy` | 대조군. 비교 대상, 대조 항로, 하락 구간 |
| `pending` | 검증 전. **이 하나에만** 씁니다 |

`pending`은 오류가 아니라 "아직 출처가 확정되지 않음"입니다. 이 제품에서
경고해야 할 것은 대부분 '틀렸다'가 아니라 '아직 모른다'입니다.

## 근거가 없으면 그리지 않는다

이 제품의 모든 화면 규칙이 여기서 나옵니다. 수치 옆에는 근거 칩이 붙고,
관계선에는 의미와 출처가 붙고, 검증되지 않은 것은 검증되지 않았다고 표시됩니다.
스키마가 이를 강제하므로 디자인도 그 상태를 드러낼 자리를 늘 비워 둡니다.

빈 상태를 그리지 마세요. 근거가 없으면 **아예 그리지 않는 것**이 기본 동작입니다.

## 면과 선

**그림자를 쓰지 않습니다.** 면은 `stone` 1px 헤어라인으로 나눕니다.
`shadow-subtle`은 진짜로 떠 있어야 하는 것 — 드로어, 팝오버 — 에만 씁니다.
카드에는 쓰지 않습니다.

## 반경은 역할을 말합니다

모든 것을 같은 값으로 둥글리지 않습니다. 둥근 정도가 그 물건이 무엇인지 알립니다.

- `radius-pill` — 누를 수 있는 것. 버튼, 탭, 칩, 태그
- `radius-card` 20px / `radius-card-lg` 24px — 담는 것
- `radius-sm` 10px — 블록
- `radius-input` 4px — 입력창. 거의 각집니다

## 글자

디스플레이는 **가볍고 크게**(300), 자간을 좁힙니다(-0.02em). 제목을 굵게 키우지
않는 것이 이 시스템의 성격입니다. 무게 대비가 아니라 크기 대비로 위계를 만듭니다.

수치는 고정폭(`mono`)입니다. 지도를 끌거나 차트를 훑는 동안 자릿수가 흔들리면
읽을 수 없습니다.

`ash`는 본문 대비 기준(4.5:1)에 못 미칩니다. ElevenLabs 원값을 그대로 두되,
뜻이 담긴 글에는 쓰지 않습니다 — 날짜나 단위 같은 장식적 표기에만.

## 여백

`space-24`(96px)가 씬과 씬 사이입니다. 이 간격 하나가 "여기서 한 장면이 끝났다"를
알립니다. 좁히면 스크롤이 이어지는 한 편의 글처럼 읽힙니다.

카드 안쪽은 `space-8`(32px). 좁은 화면에서도 `space-5`(20px) 아래로 내려가지
않습니다.

## 모션

값은 하나를 공유합니다: `cubic-bezier(0.16, 1, 0.3, 1)`.

| 무엇 | 시간 |
| --- | --- |
| 마이크로 인터랙션 | 150–250ms |
| 패널 전환 | 250–400ms |
| 씬 전환 | 320–420ms |
| 스토리 애니메이션 | 사용자 제어 |

**끌고 있는 동안에는 전환을 끕니다.** 스크럽 중에 보간이 걸리면 손과 화면이
어긋납니다.

`prefers-reduced-motion: reduce`에서는 자동 넘김과 카운트업을 끄고 최종 상태만
보여줍니다. 멈출 수 없는 자동 재생은 접근성 실패입니다.

## 접근성

- 드래그로만 되는 조작을 만들지 않습니다. 지도의 배는 `role="slider"`이고
  화살표·Home·End로 똑같이 움직입니다.
- 모든 씬에 스크린리더용 서술을 둡니다. 그 서술이 "Card First, **Text Later**"의
  Text입니다.
- 포커스 링은 `ink` 2px, offset 2px.
- `navy`와 `burgundy`는 색만으로 구분하지 않습니다. 실선/점선, 채움/빗금처럼
  형태를 함께 씁니다 — 색각 이상에서도 비교가 읽혀야 합니다.

## 단일 테마입니다

밝은 테마 하나뿐입니다. ElevenLabs가 그렇고, 자료를 나란히 놓고 비교하는
화면에는 흰 바탕이 맞습니다. 어두운 테마를 원하면 색을 뒤집는 것으로는 안 되고
따로 설계해야 합니다.
