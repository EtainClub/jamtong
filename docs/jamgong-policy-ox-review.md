# 잼공 정책 팩트 알기(O/X) 점검 (2026-11-28)

> 이재명 정부부터 공부하는 사람이 업적 14건 뒤에 바닥나지 않게, 위키의 정책 팩트로 1단계 O/X를 만들었다.
> 문항은 `src/content/study/policyOx.ts`, 검사는 `validatePolicyOx`(`pnpm validate`).

## 숫자

- 대상: 확인된 FACT claim이 3개 이상인 정책 184건(전체 235건).
- 문항: **552개** — 정책마다 O 둘·X 하나.
- 잼공에서: 정책 단원 184개가 1단계부터 열린다(정책 팩트의 길, 오늘의 한 판은 업적 뒤에 정책 단원으로 이어진다).

## 초안과 점검

초안은 Codex(GPT)가 정책마다 **확인된 claim만** 보고 썼다. 업적 O/X(ox.ts)와 같은 규칙에 더해 기계 검사를 붙였다.

| 검사 | 내용 |
|---|---|
| 근거 실재 | claim이 그 정책에 있고 확인된 것(O·X 모두) |
| 주장을 사실처럼 쓰지 않기 | O 문항의 근거가 부처 주장(CLAIM)이면 주장한 쪽이 문장에 있다 |
| 해석을 외우게 하지 않기 | 근거가 해석·의견뿐인 O 문항은 안 된다 |
| 숫자 | 문장·풀이의 숫자는 근거 claim이나 정책 제목에 있다 |
| 중복 | 한 정책 안에서 같은 문장이 두 번 나오지 않는다 |

초안 552개 가운데 기계 검사에 걸린 것은 19개였다. 16개는 정책 제목의 숫자(「2026년」 「5·18」 「제3차」)여서 검사가 제목을 함께 보게 했고, 남은 셋은 고쳤다.

- 소방 예산: 「2027년 예산안」의 연도가 근거 claim에 없다 → "정부 예산안에서 … 2026년보다 늘었다".
- 테슬라 FSD: X 문항의 「HW3」 → "이미 팔린 모든 테슬라 차량에 적용된다"(근거는 미국산 HW4만 대상).
- 북한 미사일: 「합참은」 → 「합동참모본부는」(주장한 쪽 이름을 그대로).

**X 문항 184개는 하나씩 근거와 대조해 읽었다.** 모두 근거 claim이 곧바로 바로잡는 문장이다(계획→완료, 일부→전체, 대상 착각, 방향 반대).
한 문항의 오타(「대통령의 Y에서」)를 고쳤다. **O 문항은 30개를 뽑아 읽었고** 고칠 것이 없었다. 부처·검찰 주장이 근거인 O 문항은 주장한 쪽을 문장에 넣었다("검찰은 … 라며 기소했다").

## 같이 고친 것

- 정책 단원이 은행에 두 번 들어가던 문제 — 2단계 문항을 만드는 쪽이 정책 알기로 이미 만든 단원을 다시 만들었다(26개). 단원 id 중복 검사를 테스트에 넣었다.
- 첫 3분 문제는 업적에서만 고른다 — 첫 화면 은행(entryBank)에는 업적 알기만 싣기 때문이다. 정책 알기는 전체 은행과 함께 받는다.
- 전체 은행 주소에 내용 해시를 붙였다(`/study/bank.json?v=…`). 배포로 은행이 바뀌면 주소가 바뀌어 브라우저에 남은 옛 은행을 쓰지 않는다. 같은 주소의 은행은 하루 동안 캐시한다.

## 알아 둘 것

- 정책 팩트에는 논란·해명 성격의 페이지가 많다(대통령 재판, 의혹 해명 등). 문항도 그 사실관계를 묻는다 — 근거가 확정 판결·공식 기록이라 그대로 두었다.
- 정책 단원의 순서는 정책 목록(`src/content/policies/index.ts`) 순서다. 순서를 바꾸려면 그 목록을 손본다.
