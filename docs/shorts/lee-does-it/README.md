# 쇼츠 대본 — 『이재명은 합니다』

자서전 한 장에 쇼츠 하나. 장 페이지(`/books/lee-does-it/<장 slug>`)의 숏츠 자리에 들어간다.

## 업적 대본과 다른 점

책에는 claim이 없다. 이 장의 근거는 그 장의 본문(`src/content/books/2017-he-does/text/NN.md`)이고,
화면의 「쉽게 보기」 토막이 본문의 한 문장을 그대로 옮겨 둔 자리다. 그래서 대본의 근거 칸에는
claim id 대신 **쉽게 보기 토막 id**(`d1-p2` 같은 것, `chapters.ts`)를 단다. 토막에 없는 내용은
본문 문단을 직접 가리킨다(`본문`).

## 모든 장에 공통으로 지킬 것

1. **책은 2017년 무렵의 저자의 이야기다.** 성남시장 시절에 쓴 책이다. "대통령이 ~했다"로
   바꿔 말하지 않는다. 그때의 생각과 구상은 결과가 아니다.
2. **책에 적힌 수는 책에 적힌 수로 말한다.** 공약 이행률, 채무, 국방 예산 같은 수는 "책에
   따르면"을 붙인다. 업적 페이지와 다를 수 있는 수(16장 채무)는 영상에서 단정하지 않는다.
3. **다툼이 있는 대목은 저자의 설명이라고 말한다.** 10장(청와대 보고서·종북 공세), 11장(형 가족),
   19장(검사 사칭 사건)은 "저자는 ~라고 말합니다"로 주어를 밝힌다. 19장의 벌금형은 빼지 않는다.
4. **1장의 극단적 선택 대목은 방법을 말하지도 보여 주지도 않는다.** 마지막 카드에 상담 전화
   109를 넣는다.
5. **다른 사람을 깎아내리는 장면을 만들지 않는다.** 아버지, 형, 상대 후보, 전직 대통령 등
   실존 인물은 책의 문장 이상으로 그리지 않는다. 얼굴을 그리지 않는다.
6. **마지막에 장 주소를 남긴다.** 요약 본문과 쉽게 보기가 그곳에 있다.

## 만드는 흐름

```
대본(이 폴더) → NotebookLM 영상 개요 생성 → 유튜브 쇼츠 업로드
             → 2017-he-does/chapters.ts 그 장의 shorts[]에 youtubeId 등록
```

NotebookLM에는 그 장의 `text/NN.md`를 통째로 소스로 넣고, 각 파일의 「커스터마이즈 프롬프트」를
지시문 칸에 넣는다. 생성된 영상은 초안이므로 대본과 대조한 뒤 올린다. 본문을 이 폴더에
복사해 두지 않는다 — 같은 글이 두 군데 살면 조용히 갈라진다.

공통 화면 톤: 남색(주체)과 짙은 붉은색(대가·상처), 밝은 흰색 바탕. 차분한 설명 톤, 감탄사와 과장 없이.
