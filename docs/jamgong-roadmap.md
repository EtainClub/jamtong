# 잼공 발전 계획 — 가볍게 시작해서, 근거로 판단하고 말하는 힘까지

> 상태: **계획 2판 확정 (2026-11-28)**. 앞선 문서: `docs/daily-study.md`(1·2판 설계와 3.0 구현 현황).
> 1판은 사용자가 낸 "들은 말의 사실관계를 스스로 가려내는 사람" 계획을 점검하고 고친 것이다.
> 2판은 운영자 결정을 반영했다. **AI 코치는 넣지 않는다 · 도는 말 판정은 사람이 승인한다 · 슬롯 무료 한 번은 유지한다.**
> 그리고 **처음 온 사람이 복잡해서 떠나지 않게 가볍게 시작하고, 단계적으로 올라가는 학습 경로**를 세웠다.

## 0. 목적 — 두 층

| 층 | 목적 | 누가 | 이것만 해도 성공인가 |
|---|---|---|---|
| **1차** | 업적·정책의 **기초 사실관계를 확인하고 익힌다.** 무엇을 했고, 어디에 적혀 있고, 아직 모르는 것은 무엇인지 | 모든 사용자 | **그렇다.** 대부분의 사용자가 여기 머물러도 잼공은 제 일을 한 것이다 |
| **2차** | 그 기반 위에서 **판단력을 기른다.** 사실과 주장 가르기, 숫자와 비약 따지기, 비난에 근거로 답하기 | 더 하고 싶은 사람 | 지향점은 이재명 대통령이 공개 토론에서 보여 주는 수준이다. 모두가 닿을 필요는 없다 |

문제를 풀고 답을 맞히는 것은 목적이 아니다. 기능을 넣을 때마다 묻는다. **"이 연습을 하고 나면, 처음 듣는 말 앞에서 무엇을 더 잘하게 되는가?"**

앱 화면에서는 "대통령처럼" 같은 문구를 쓰지 않는다. 목표는 근거로 말하는 힘이지 특정인 흉내가 아니다.
그렇게 쓰면 받는 사람에게 동원 도구로 보이고, 객관성 원칙(`garden-game.md` §1)과도 맞지 않는다.

### 2.2 고칠 것 (요약)

1. **반론 90건은 이미 "공격 질문 + 근거로 쓴 모범 답변" 짝이다.** "반론 고르기"로만 쓰기에는 아깝다. 새 글 없이 비난 대응 연습이 된다.
2. **연습이 고르기에서 끝난다.** 판단력과 대응력은 직접 해 봐야 자란다. 단, 이것은 위 단계에서만 요구한다(§3).
3. **"자동으로 만든다"는 반만 맞다.** 주장 claim에는 "○○부는 …라고 밝혔다"가 문장 안에 있다. 그대로 내면 판단이 아니라 문형 맞히기가 된다. 귀속 표현을 덜어 다시 써야 한다(Codex 초안 → 에이전트 대조).
4. **도는 말 판정이 근거보다 세게 말할 위험.** 부처 해명은 "사실 아님"의 근거가 아니다(§6 R5).
5. **지표가 행동만 잰다.** 열람·복사 수는 관찰만 하고, 능력은 처음 보는 문장으로 잰다(§7).
6. **지금 X 문항 56개는 GPT가 지어낸 오해다.** 실제로 도는 말인지 확인되지 않았다.
7. 출처의 기사 제목으로 "제목과 근거" 문항을 만들 수 있다. 속통 확장을 기다릴 필요가 없다.

## 3. 학습 경로 — 다섯 단계

잼공의 뼈대는 **단계(레벨)**다. 단원(업적·정책)은 무엇을 공부하는지이고, 단계는 **어떤 힘을 쓰는지**다.
같은 대장동 단원도 1단계에서는 "무엇이었나", 4단계에서는 "유죄 판결을 묻는 사람에게 어떻게 답하나"를 연습한다.

| 단계 | 이름 | 할 수 있게 되는 것 | 연습 (기술) | 한 문제에 드는 품 |
|---|---|---|---|---|
| **1** | 🌱 **알기** | 무엇을 한 정책인지 말하고, 근거가 어디 있는지 안다 | O/X 내용 알기(A0) · 「원문 보기」 · 근거 카드 모으기 | 탭 한 번, 10초 |
| **2** | 🌿 **가리기** | 들은 문장이 확인된 사실인지, 누구의 주장인지, 해석인지 가른다. 숫자가 전망인지 실적인지 본다 | 층 가르기(A1) · 숫자 읽기(A3) | 보기 셋 중 하나, 15초 |
| **3** | 🔍 **따지기** | 아직 확인 안 된 것을 알아보고, 자료의 무게를 재고, 비약과 과장된 제목을 짚는다 | 확인 수준(A2) · 자료 무게(A4) · 비약 찾기(B1) · 제목과 근거(B2) · 도는 말 판정(C2①) | 보기 넷 + 확신도, 30초 |
| **4** | ⚖️ **답하기** | 공격 질문에 인정할 것은 인정하고 근거로 답한다. 약점을 먼저 꺼낸다 | 쟁점에 답하기(C1 ①②) · 약점 먼저 말하기(C3) · 대화 답장(C4) | 근거 카드 2~3장 고르기, 1분 |
| **5** | 💬 **말하기** | 처음 보는 쟁점에 30초 안에 근거 하나를 붙여 직접 말한다 | 직접 말하기·쓰기(C1③) · 30초 설명 · 말의 뼈대(B3) | 소리 내어 말하고 네 칸 자가 점검, 2분 |

- **1단계가 1차 목적이다.** 2단계부터가 판단력이다. 5단계가 지향점이다.
- 단계가 오를수록 한 문제에 드는 품이 커진다. 처음 온 사람은 가장 가벼운 것만 본다.

### 3.1 단계는 어떻게 열리나

- **조건은 "해 본 것"이다. 점수가 아니다.** 1단계에서 근거 카드 10장을 모으면 2단계 초대가 뜬다. 2단계 문제를 20개 풀면 3단계 초대가 뜬다. 그다음 단계도 같은 식이다.
- **초대이지 강요가 아니다.** "다음 단계를 열까요? 문제가 조금 더 생각할 거리가 생겨요. / 지금처럼 할게요"를 묻는다. 거절해도 같은 단계를 계속 즐길 수 있고, 2주 뒤에 한 번 더 묻는다.
- **「지금 단계에 머물기」 설정**을 둔다. 1단계에만 머무는 사람은 실패가 아니다.
- **내려가는 일은 없다.** 오래 쉬었다 와도 단계는 그대로이고, 복습이 조금 늘 뿐이다.
- 이미 아는 사람을 위해 **「건너뛰기 점검」**을 둔다(선택). 해당 단계 문제 6개 가운데 5개를 맞히면 그 단계를 연 것으로 친다. **4단계 「답하기」가 생긴 뒤(R3)에 켠다** — 그 전에는 건너뛰어 갈 곳이 마땅치 않다.

### 3.2 오늘의 한 판은 단계에 맞춘다

- 지금 단계 문제 **70%** + 아래 단계 복습 **30%**. 아래 단계 복습은 기초 사실을 잊지 않게 한다.
- 판의 길이도 단계에 맞춘다. **1단계 5문제(2분) → 2·3단계 8문제 → 4·5단계 연습 2~3개.**
- 4·5단계는 「오늘의 한 판」과 별도로 「오늘의 연습 하나」로 둔다. 무거운 연습이 매일의 리듬을 깨지 않게 한다.

### 3.3 화면은 단계만큼만 보인다 (점진적 공개)

| 단계 | 보이는 것 | 숨기는 것 |
|---|---|---|
| 1 | 교실(오늘의 한 판) · 배움길 · 근거노트 · 내 기록 | 말하기 탭, 확신도, 「준비 중」 칸, 실력 점검 |
| 2 | + 근거 카드의 층 거르기 | 말하기 탭, 확신도 |
| 3 | + 확신도 · 「확인 불가」 보기 · 실력 점검 · 「이번 주 도는 말」 | 말하기 탭 |
| 4 | + **말하기 탭**(쟁점 연습 · 대화 답장) | — |
| 5 | + 직접 말하기 · 30초 설명 | — |

- 말하기 탭은 4단계 전에는 하단 탭에 보이지 않는다. 1단계 사람의 하단 탭은 넷이다.
- 「준비 중」은 그 단계에 닿은 사람에게만 보인다. 처음 온 사람은 만들다 만 칸을 보지 않는다.

## 4. 첫 3분 — 떠나지 않게

**지금:** 인사 → 하루 목표 고르기 → 8문제.
**바꾼 뒤:** 들어오자마자 문제 하나 → 맞히든 틀리든 근거 카드 한 장 → 두 문제 더 → 끝.

| 순서 | 화면 | 시간 |
|---|---|---|
| ① | 잼통이 한 줄: "30초면 돼요. 하나만 풀어 볼까요?" + **첫 문제가 바로 보인다** | 10초 |
| ② | 답하면 풀이 + **근거 카드 한 장이 근거노트에 들어가는 연출** | 15초 |
| ③ | "두 개만 더?" → 2문제 (가장 많이 알려진 업적에서, 쉬운 O 문항 위주) | 40초 |
| ④ | 끝: 오늘 도장 + 근거 카드 3장 + "내일 또 와요"(알림은 묻지 않는다) | 10초 |
| 다음 날 | 하루 목표 고르기를 **그때** 묻는다. 기본값은 「가볍게 1판」 | — |

- 첫 문제는 업적 28건 가운데 **첫 방문 정답률이 높고 근거가 짧은 것**에서 고른다. 지표를 보고 바꾼다.
- 첫날에는 점검·확신도·단계 설명·정원 이야기를 꺼내지 않는다.
- 원본 페이지의 「1분 확인 문제」로 들어온 사람은 이미 한 문제를 푼 것으로 친다. ①을 건너뛴다.

## 5. 연습 방식 (2단계부터)

### 5.1 고르기 → 근거 붙이기 → 직접 말하기
- 2·3단계는 고르기(①)가 중심이다.
- 4단계는 근거 붙이기(②)가 중심이다. 예: 「관련자들이 유죄 판결을 받지 않았나?」에 인정할 사실(1심 유죄)과 함께 읽을 사실(공공용지 53.5%)을 고른다.
- 5단계는 직접 말하기(③)가 중심이다. 내 답을 원본 모범 답변(`response`)과 나란히 놓고 네 칸으로 스스로 점검한다.
  인정했나 / 근거를 댔나 / 과장이 없나 / 모르는 건 모른다고 했나.
- **AI가 답을 채점하거나 피드백하지 않는다(운영자 결정).** 견줄 대상은 원본의 모범 답변과 네 칸 점검표뿐이다.

### 5.2 확신도와 "모르겠다" (3단계부터)
- 답과 함께 확신도를 고른다(확실 / 아마 / 모르겠다). 「이 자료로는 알 수 없다」를 보기에 늘 둔다.
- 풀이는 정답보다 **무엇을 보고 가렸는지(단서)**를 먼저 보인다.
- 확신하고 틀린 문항을 다시 볼 것 맨 앞에 둔다.

### 5.3 실력 점검 (3단계부터, 선택)
- 문항을 연습용과 점검용으로 나눈다. 점검용은 레슨에 나오지 않는다.
- 4주마다 12문항을 낸다. 결과는 기술별 꽃밭으로만 보인다. 점수와 순위는 없다.

## 6. 단계별 구현 계획

**R1 → R2 → R3 → R4 → R5 → R6.** 사용자가 걷는 순서대로 만든다. 1단계를 가볍게 다듬는 것이 첫 일이다.

### R1. 가벼운 입구 + 기반 (1~2주) — **구현 (2026-11-28, 브랜치 `feat/jamgong-r1`)**

> 된 것: 첫 3분(첫 화면에 바로 문제 → 근거 카드 → 두 문제 더 → 끝, 하루 목표는 다음 날), 1단계 판 5문제,
> 단계 뼈대(`study/levels.ts` — 초대·머물기·거절 14일, 문항 없는 단계로는 초대하지 않음), 단계만큼 보이는 탭·칸(`nav.ts`),
> 계정 저장(`users/{uid}/study/state`, 두 기기 기록을 합침 — `study/sync.ts`, 규칙 + `pnpm check:study-rules`),
> 문항을 `src/content/study/ox.ts`로 옮김, `pnpm validate` 문항 검사(`src/content/study/validate.ts`), X 문항 점검(`docs/jamgong-ox-review.md`).
> 남은 것: **Firestore 규칙 배포**(배포 전에는 계정 읽기가 막혀 이 기기에만 저장된다 — 화면은 그대로 돈다).

- **첫 3분**(§4): 첫 화면에서 바로 문제, 첫 판 3문제, 하루 목표는 다음 날 묻는다.
- **1단계 판 길이 5문제.** 1단계 사람의 하단 탭은 넷이다. 「준비 중」 칸을 숨긴다(§3.3).
- **단계 뼈대**: `StudyData.stage`(1~5), 초대·머물기, 문항마다 `stage`·`skill` 태그. 단계 이름은 알기·가리기·따지기·답하기·말하기로 확정.
- 기록을 계정(Firestore `studies/{uid}`)에 저장하고 규칙 검사를 단다. 사람이 쓴 답은 기기에만 둔다.
- 문항을 `src/content/study/`로 옮긴다(문항 id 그대로). `pnpm validate` 문항 검사:
  - 앵커가 실재하는가.
  - 원본보다 센 층으로 쓰지 않았는가.
  - 미검증 claim을 정답 근거로 쓰지 않았는가.
- X 문항 56개를 다시 본다(§2.2의 6).

### R2. 2단계 「가리기」 (2~3주)
- **층 가르기**: claim을 귀속 표현 없는 짧은 문장으로 다시 쓴다(Codex 초안 → 에이전트 대조). 보기는 "확인된 사실 / ○○의 주장 / 해석".
- **숫자 읽기**: 전망인가 실적인가, 언제 기준인가, 누가 셈했나. 핵심 숫자 95개와 숫자가 든 정책 claim을 쓴다.
- 2단계 초대(근거 카드 10장)를 켠다. 근거노트에 층 거르기가 열린다.

### R3. 4단계 「답하기」 재료 먼저 (2주)
- 3단계보다 먼저 만든다. **반론 90건은 새 글이 거의 필요 없고, 도는 말 판정(R5)은 사람 승인을 기다려야 해서 느리다.**
- **쟁점 연습**: 반론의 질문 → 답의 뼈대 고르기(인정 + 근거 / 부정 / 화제 돌리기) → 근거 카드 고르기 → 모범 답변 보기.
- **약점 먼저 말하기**: 정책 비판 239건 가운데 인정할 것 고르기.
- **대화 답장**: 업적 X 문항의 오해와 반론 질문을 지인 메시지로 쓴다(도는 말은 R5 승인 뒤에 더한다).
- 말하기 탭은 4단계에서 열린다. **「건너뛰기 점검」을 이때 켠다** — 그 전에 열고 싶은 사람은 점검으로 올라온다.

### R4. 3단계 「따지기」 (2~3주)
- **확인 수준**: 미검증 111, 확인 못 한 것 629 → "아직 확인된 게 아니다". 앵커는 `policy:<slug>`.
- **자료 무게**: "어떤 종류의 자료가 있어야 이 말이 확정되나".
- **비약 찾기**: 언행 caveat 32, X 문항.
- **제목과 근거**: 출처 기사 제목 vs claim.
- 확신도, 「모르겠다」, 실력 점검을 이 단계에서 켠다.

### R5. 도는 말 판정 — 사람 승인 (3주, 승인 속도에 따라)
- `rumorSchema`에 판정을 더한다. 위키 정책 페이지와 factbase에도 같이 나간다.

  ```ts
  verdict?: {
    value: "true" | "partly" | "false" | "official-only" | "unknown";
    note: string;          // 대응 claim만으로 쓴 한두 문장
    approved?: string;     // 사람이 승인한 날 "YYYY-MM-DD". 에이전트는 이 칸을 쓰지 않는다
  }
  ```

- **규칙**
  - 판정은 연결된 claim만으로 설명한다.
  - 부처 해명만 있으면 `official-only`(「정부 해명만 있음」)이고 `false`가 아니다.
  - 미검증이 섞이면 `unknown`이다.
  - `validate`가 판정과 근거 층이 맞는지 본다.
- **승인 흐름**
  1. 에이전트가 `verdict`(value·note)를 초안으로 쓴다. `approved`는 비워 둔다.
  2. 운영자가 PR에서 읽고 `approved`에 날짜를 적는다.
  3. 잼공·위키·factbase는 `approved`가 있는 판정만 보인다.
  - AGENTS.md "정부 정책 팩트"에 "에이전트는 `verdict.approved`를 쓰지 않는다"를 더한다.
  - 승인 대기 목록은 `pnpm study:verdicts`로 뽑는다.
- 문항: 「이 말, 맞을까?」(3단계) → 「한 줄로 답하기」(4·5단계). 교실의 「이번 주 도는 말」은 3단계부터 보인다.

### R6. 5단계 「말하기」와 뉴스 (2주 + 상시)
- **직접 말하기·쓰기**: 쟁점 질문에 내 답을 말하거나 쓰고, 모범 답변과 네 칸 자가 점검. 쓴 글은 기기에만 둔다.
- **30초 설명**: 열매 단원을 소리 내어 설명하고 자가 점검.
- **말의 뼈대**: 연설의 쉬운 토막으로 주장·근거·예시 가르기. 편집자가 나눈 것임을 밝힌다.
- 속통 연결이 늘면 「오늘의 뉴스 한 문장」을 더한다.

| 층 | 본다 | 어떻게 |
|---|---|---|
| **입구** | 첫 3분을 끝까지 했나 | 첫 판 완료율, 다음 날 재방문(D1) |
| **1차 목적** | 기초 사실을 익히고 있나 | D7 재방문, 근거 카드 수, 「원문 보기」를 연 비율 |
| **2차 목적** | 판단력이 느는가 | 실력 점검 변화(처음 보는 문장, 기술별), 확신하고 틀린 비율, 「확인 불가」를 고르는 비율 |
| 단계 | 어디서 멈추나 | 단계 분포, 초대 수락률, 「머물기」 비율. 머물기는 실패로 보지 않는다 |

정답률과 푼 문항 수는 목표로 두지 않는다. 분석 이벤트에는 단계·기술·정오·확신도만 보낸다. 쓴 답은 보내지 않는다.

## 8. 지킬 선

- **입구는 가볍게 둔다.** 첫날에는 문제 세 개와 근거 카드뿐이다. 설정, 설명, 점검은 미룬다.
- **1단계에 머무는 사람도 성공이다.** 다음 단계는 초대할 뿐이고, 재촉하는 알림을 보내지 않는다.
- **AI가 답을 채점하거나 글을 쓰지 않는다.** 견줄 대상은 원본 모범 답변과 점검표다.
- **도는 말 판정은 사람이 승인한 것만 보인다.** 판정은 근거보다 세게 말하지 않고, 해명은 해명으로 적는다.
- 모범 답에서 인정할 것을 빼지 않는다. 연습은 상대를 이기는 기술이 아니라 사실대로 말하는 기술이다.
- X 문항과 도는 말 문장은 문제 화면에서만 보이고, 곧바로 근거가 붙는다.
- 반론과 비판을 "물리칠 대상"으로 그리지 않는다.
- 앱 문구는 특정인 흉내를 말하지 않는다.
- **보상은 지금대로 둔다.** 하루 목표를 채우면 잼 30과 슬롯머신 무료 한 번이다(운영자 결정). 단계가 올라가도 보상을 키우지 않는다. 4·5단계 연습에 따로 보상을 걸지 않는다.
