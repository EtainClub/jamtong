잼통 정원 · 아이소 방 0단계 시안

투시·크기·층을 정하려는 시안이다. 가구는 GPT로 만든 시범 도트 그림이고(상자 자리표시로 바꿔 볼 수 있다), 꼬마는 실제 그림(AvatarFigure)이다. 물건을 끌어서 옮기고, 보관함에서 끌어 넣어 본다.

타일 너비 방 가구

보관함

누르면 빈 자리에 놓이고, 끌면 원하는 자리에 놓인다. 라디오를 책상 위로 끌면 책상에 올라간다. 꼬마를 의자나 침대에 끌어 놓으면 앉거나 잔다.

작은 화면에서

같은 방을 줄여 그렸다. 가장 작은 곳에서도 침대·책상·꼬마가 구별되는지 본다.

공유 카드 (1200×630의 1/3 크기)
1촌 목록 썸네일 (가로 120px)

크기·기준점 표

그림 상자는 바닥 크기와 높이에서 정해진다. 가로 = (w + d) × 타일/2, 세로 = (w + d) × 타일/4 + 높이. 기준점은 바닥의 앞 꼭짓점이다.

공개 문서에 실릴 모양

물건 하나가 짧은 문자열 하나다. 바닥: id~u×2~v×2~방향[~받침번호], 벽: id~L|R~가로×2~높이.

이 시안으로 정할 것

  1. 타일 너비 40px로 정했다(2026-11-21). 꼬마(40×48)가 타일 한 칸 너비다. 10×10 방은 폰에서 0.8배쯤 줄여 보인다. 32px는 비교용으로 남긴다.
  2. 방 크기 6/8/10 정사각으로 정했다. 지금 바닥 12/16/20칸이 36/64/100타일이 된다.
  3. 벽 높이 120px — 꼬마(48px)의 2.5배.
  4. 음영: 윗면 원색, 왼쪽 면 12% 어둡게, 오른쪽 면 25% 어둡게. 외곽선은 잉크색 1px.
  5. 꼬마는 정면을 본다. 방이 돌아도 꼬마 그림은 하나다.
  6. 가구 도트 그림은 GPT로 만들었다(pnpm room:iso-gen). 방향마다 두 장(뒤가 먼 쪽·가까운 쪽)이고, 나머지 두 방향은 좌우 반전이다.
