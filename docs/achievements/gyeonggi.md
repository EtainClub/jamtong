## 2. 묶기 제안 — 아홉 갈래

항목 하나가 업적 하나가 되면 67개짜리 목록이 되고, 그건 이 사이트가 버린
형태다(단위는 업적이지 항목이 아니다). **같은 논지를 갖는 것끼리 묶는다.**

묶음의 기준은 주제가 아니라 **그 묶음이 무엇을 주장하는가**다.

| 묶음 | 항목 | 이 묶음이 말하는 것 | 어울리는 씬 |
|---|---|---|---|
| **A. 계곡·하천 정비** | 8 | 다들 불가능하다던 것을 설득으로 해냈다 | `quantity-track`(철거 진행), `composition`(시설 종류) |
| **B. 재난기본소득과 지역화폐** | 51, 54 | 성남 청년배당에서 이어진 계보, 전 도민 지급 | `money-flow`, `quantity-track` |
| **C. 신천지 대응** | 7 | 명단을 달라고 기다리지 않았다 — 속도 | `quantity-track`(열하루), `composition`(동원 인력) |
| **D. 공공의료와 응급** | 3, 9, 43, 52 | 성남시의료원에서 이어지는 공공의료 | `quantity-track`, `composition` |

남는 것(11, 16, 19, 20, 29, 32, 38, 39, 41, 42, 44, 47, 50, 58, 60, 63, 64)은
어느 묶음의 논지에도 딱 맞지 않는다. **억지로 끼우지 않는다.** 세부 성과
목록(`src/content/milestones/`)에 넣거나, 나중에 묶음이 자랄 때 합류시킨다.

### 먼저 할 셋

한 번에 아홉을 만들지 않는다. 성남시도 넷을 차례로 했다.

1. **A. 계곡·하천 정비** — 단일 사건이라 경계가 뚜렷하고, 경기도 보도자료에
   철거 시설 수·구간이 수치로 남아 있다. 반대도 컸으므로 반론 섹션이 살아난다.
2. **B. 재난기본소득과 지역화폐** — 성남 청년배당과 이어지는 계보가 이 사이트에
   이미 있다(`seongnam-welfare`). `money-flow` 씬이 그대로 맞는다.
3. **C. 코로나 대응** — 시점이 또렷해서 `quantity-track`이 맞고, 신천지 전수조사는
   날짜와 대상 수가 기록으로 남아 있다.

## 3. 근거 — 어디서 찾나

책은 `src-book`으로 싣되 **수치의 근거로 쓰지 않는다.** 성남시 때 책의
"3년 만에 5,400억"이 실제로는 "3년 6개월에 7,285억"이었다. 틀린 수는 출처가
책이어도 고쳐 싣는다.

항목별 1차 자료의 자리:

| 종류 | 어디 | `SourceType` |
|---|---|---|
| 경기도 보도자료·정책자료 | gg.go.kr 뉴스 | `official` |
| 조례 | 경기도 자치법규정보시스템 / 국가법령정보센터 | `legislative` |
| 통계 | 경기도 통계, KOSIS | `statistics` |
| 평가·지표 | 한국매니페스토실천본부, 행정안전부 | `official` |
| 당시 보도 | 언론사 기사 | `press` |
| 본인 발언 | 이재명 SNS·블로그 원문 | `statement` |

**62번(지표 12개)은 그대로 쓰지 않는다.** 책은 블로그를 출처로 달아 두었다.
'전국 1위' 같은 순위는 평가 주체와 연도와 기준이 함께 적히지 않으면 `FACT`가
아니다. 매니페스토실천본부 원자료를 찾아 붙이거나, 못 찾으면 싣지 않는다.

## 4. 싣지 않을 것

**'물고 가자' 네 구간(전과4범 / 행복이 / 형수욕설 / 자살).**
업적이 아니라 의혹에 대한 반박이다. 세 가지 이유로 뺀다.

1. 이 사이트의 단위는 업적이다. 반박문은 업적이 아니다.
2. 형수욕설·자살 구간은 제3자의 가족사와 사망에 관한 내용이다. 당사자가 아닌
   사람의 사생활과 죽음을 정치적 재료로 옮기지 않는다.
3. 다툼이 있는 사안은 업적의 **반론 섹션**에서 근거로 답하는 자리가 이미 있다
   (대장동이 그렇게 되어 있다). 별도의 반박 페이지를 만들 이유가 없다.

**10번은 경기도 항목이 아니다.** 성남시 여성 안전화장실 건이 2학기 장에 섞여
있다. 경기도 업적으로 등록하면 사실이 틀어진다. 성남시 쪽으로 보내거나 뺀다.


**21번(드라이브 스루)은 경기도의 업적이 아니다.** 책은 "경기도 공무원의 아이디어를
빠르게 채택 적용했어"로 적지만, 전국 최초 드라이브 스루 선별진료소는 고양시가
2020년 2월 26일에 연 '안심카 선별진료소'다(대통령상 수상). 고양시는 경기도 안의
기초지자체이지 경기도가 아니다. 남의 공을 가져오면 나머지 근거까지 의심받는다.
그래서 C 묶음에서 뺐고, 22번(의료원 특별휴가)은 단독으로 업적이 되기에 얇아
세부 성과로 남긴다. C는 7번 하나로 좁혔다.

**67번(일산대교)은 빼지 않는다.** 무료화 28일 만에 유료로 돌아갔다고 책 스스로
적는다. 성공만 골라 실으면 그건 자료가 아니라 선전물이다. 교통 묶음 안에
결말까지 적어 싣는다.

## 5. 등록 절차

업적 하나를 만드는 순서다. `pnpm check`가 각 단계를 검사한다.

### ① 콘텐츠 파일

```
src/content/achievements/<slug>/achievement.ts
```

파일 머리 주석에 **무엇을 왜 이렇게 묶었는지**를 적는다. 성남시 파일들이
그렇게 되어 있다 — 책의 수치를 고친 이유, 한 사람의 공으로 몰지 않은 이유가
코드에 남아 있어야 나중에 판단을 되짚을 수 있다.

채울 것:

- `publishStatus` — 근거가 얇으면 `"draft"`로 시작한다
- `sourceNote` — 근거의 한계. **공개한 뒤에도 화면에 계속 보인다**
- `claims` — 단정마다 `assertionType`. 다툼이 있으면 `CLAIM` + `assertedBy`
- `sources` — `license`가 `link-only`면 `quote`를 넣을 수 없다
- `timeline` / `keyNumbers` / `graph` / `eli5` / `scenes` / `counterpoints`

### ② 등록 네 군데

```
src/content/achievements/index.ts              ACHIEVEMENTS에 추가
src/features/achievement/scenes.ts             SCENES_BY_ACHIEVEMENT에 씬 목록
src/app/achievement/[slug]/page.tsx            LAYOUTS에 레이아웃·추천 질문
src/features/eli5/art.tsx                      쉬운 설명 삽화 (Eli5Art 열거형에도)
```

`scenes.ts`를 빠뜨리면 **그 업적의 AI 안내가 404로 죽는다.** 성남시 넷이 실제로
그렇게 배포됐다. `pnpm agent:check`가 잡는다.

### ③ 검사

```bash
pnpm check
```

`validate`가 막는 것: 없는 근거를 가리키는 장면, 합이 100%가 아닌 구성비,
`assertedBy` 없는 `CLAIM`, 고점에서 끝나는데 `note`가 없는 시계열.

### ④ 쇼츠 (⑦)

`docs/shorts/<slug>.md`에 장면표와 근거 id를 적어 대본을 만들고, 영상이 나오면
`shorts[]`에 `youtubeId`만 등록한다. 성남시 넷의 대본이 본보기다.

## 6. 묶을 때 지킬 것

성남시에서 실제로 문제가 됐던 것들이다.

- **한 사람의 공으로 몰지 않는다.** 여러 시정·도정에 걸친 정책은 그렇게 적는다.
  무상급식은 시작도 완성도 남의 몫이라고 적었고, 그편이 더 강했다.
- **'전국 최초'를 확인 없이 적지 않는다.** 같은 시기 여러 지자체가 경쟁적으로
  확대한 정책이 많다. 무엇을 기준으로 최초인지에 따라 답이 갈린다.
- **책의 수치를 그대로 믿지 않는다.** 유리하게 부풀린 것이든 작게 적힌 것이든
  틀린 수는 고친다. 다만 책을 출처 목록에서 빼지는 않고, 무엇이 어떻게 다른지
  적는다.
- **묶음 안에서 셈이 다른 것을 한 칸에 세지 않는다.** 모라토리엄의 7,285억과
  2018년 '채무 제로'가 서로 다른 셈이었던 것처럼, 시행된 것과 발표된 것,
  집행액과 계획액을 섞지 않는다.
